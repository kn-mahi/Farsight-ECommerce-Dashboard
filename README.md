## Farsight E-Commerce Dashboard



###### **Project Overview** 



Farsight E-Commerce Dashboard is a Data Science project focused on analyzing e-commerce data and discovering useful business insights.



The project includes data analysis, data visualization, and exploration of important patterns and trends from e-commerce datasets using R.



###### **Tools \& Technologies**



\- R

\- RStudio

\- Data Analysis

\- Data Visualization

\- CSV Dataset
